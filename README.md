### 📌 Featured Projects

**🔧 FastAPI Developer Knowledge Base**

**🌳 Ceuci — ClimateTech for Traditional Communities**
A mobile app delivering climate risk intelligence (wildfire & drought) to family farmers and traditional communities across Brazilian biomes, powered by NASA FIRMS, Open-Meteo, and Hydrocron APIs. Contributed requirements engineering, visual identity, and icon design.

**🛡️ AppSec Security Testing — OWASP Juice Shop**
Structured, ASVS-based penetration testing using Burp Suite, covering JWT session management, algorithm confusion attacks, token tampering, and IDOR vulnerabilities. Findings tracked in a custom vulnerability & test case spreadsheet.

**⚙️ OT/ICS Red/Blue Team Lab**
A Modbus-TCP attack scenario simulating an ultrasonic flow meter, built on OpenPLC, FUXA (HMI/SCADA), Conpot, and Kali Linux. Included traffic redirection, data falsification, and false alarm injection, with Python attack scripts (pymodbus) and a custom SCADA bridge.
